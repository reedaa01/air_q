# Morocco Air Quality Platform

Production-style portfolio scaffold for a Morocco-focused air quality platform.

This repository is intentionally scaffold-only at this stage. It contains a Next.js frontend shell and reference folders for future backend, data, and infrastructure work.

## Structure

```text
apps/
  frontend/       Next.js 15+ App Router frontend
  backend/        FastAPI reference folder only
infra/            Infrastructure reference folder only
```

## Frontend

```powershell
cd apps/frontend
npm install
npm run dev
```

No business logic, backend endpoints, database models, Docker, CI/CD, Terraform, or monitoring configuration is implemented.
